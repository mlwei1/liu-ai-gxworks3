# 三工位取放（半结构化需求示例）

> 这是给"规则解析器/LLM 解析器"的输入示例。行首是段名，冒号后是动作序列。
> 动作可用 `,`、`;`、`；`、`→`、`->` 分隔；括号里可以写设备号或注释。

初始化:
  SM402 置位 S0

取放站:
  步号段 100-199
  竖直缸(Y0)下降
  到位(X3) -> 夹紧(Y2)
  到位(X7) -> 延时2s
  竖直缸(Y0)上升
  原位(X2) -> 水平缸(Y1)右移
  到位(X5) -> 松开(Y2)
  原位(X6) -> 水平缸(Y1)左移
  原位(X4) -> 完成，回待机

报警:
  气缸: 竖直缸(Y0) 到位(X3) 原位(X2)
  气缸: 水平缸(Y1) 到位(X5) 原位(X4)
  气缸: 夹爪(Y2) 到位(X7) 原位(X6)
